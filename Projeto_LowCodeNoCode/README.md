# 🚀 Projeto Módulo 3 – Low Code / No Code / Vibecode

---

## 📌 Desafio Escolhido

O desafio selecionado pelo grupo foi o desenvolvimento de um **sistema de automação de envio de e-mails**.

O objetivo do projeto é criar uma aplicação funcional capaz de registrar informações de usuários e automatizar o envio de e-mails personalizados, demonstrando o uso de fluxos automatizados em uma plataforma Low Code/No Code.

A solução foi desenvolvida para simular um processo real de comunicação automatizada, como confirmações, notificações e mensagens personalizadas.

---

## 🖥️ Protótipo

- 🔗 **Link do protótipo (Bubble):**  
https://roneyprofissional11-79104.bubbleapps.io/version-test

- **Funcionamento:**  
O utilizador acessa a aplicação, preenche um formulário com dados do destinatário (nome, e-mail, assunto e mensagem) e aciona o envio. O sistema processa as informações automaticamente e executa o fluxo de envio de e-mail.

> 📁 Os prints da aplicação e do fluxo de automação estão organizados na pasta `/docs`.

---

## ⚙️ Plataforma Utilizada

- **Nome da plataforma:** Bubble (com recursos de automação e IA)

### 🎯 Justificativa da escolha

A plataforma Bubble foi escolhida por permitir o desenvolvimento rápido de aplicações web sem necessidade de programação tradicional.

Ela oferece:

- Interface visual intuitiva
- Workflows automatizados
- Banco de dados integrado
- Integração com APIs externas
- Suporte a prototipagem rápida (No Code / Vibecode)

---

## ✅ Vantagens Identificadas

1. **Desenvolvimento rápido de protótipos**
2. **Automação de processos sem código**
3. **Integração simples com APIs de e-mail**
4. **Interface visual intuitiva**
5. **Facilidade de validação de ideias**

---

## ⚠️ Limitações Encontradas

1. Customização limitada em algumas funcionalidades avançadas  
2. Dependência da plataforma (lock-in tecnológico)  
3. Escalabilidade restrita em planos gratuitos  
4. Algumas integrações exigem planos pagos  

---

## 📚 Reflexão Crítica

O grupo identificou que ferramentas Low Code/No Code são muito eficientes para criação rápida de soluções e validação de ideias.

Durante o desenvolvimento, foram utilizados workflows simples para automatizar o envio de e-mails e armazenar os dados no banco da plataforma.

Apesar das limitações, a experiência demonstrou a eficiência da abordagem para prototipagem e automação de processos.
